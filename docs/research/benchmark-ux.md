## 1. Life360 — 가족 안심 앱의 표준

### 1-1. 가족 초대 온보딩: "프리필 메시지 + 코드 하나"
- **패턴**: 초대자가 `Send Code` → OS 공유 시트 → **미리 작성된 초대 문구 + 초대 코드** 전송. 피초대자는 가입 직후 코드 입력 → 멤버 미리보기 → 수락. 전체 약 20초, 코드 72시간 만료. 위치 권한 요청은 합류 이후로 미룸.
- **심리**: 초대 문구를 대신 써줘 초대자의 사회적 어색함 제거. "문자로 온 숫자 입력"이라는 익숙한 멘탈 모델 재사용. 수락 전 멤버 미리보기 = "누가 나를 보게 되는가" 통제감.
- **적용안**: 우리는 부모님이 **앱 설치조차 필요 없는 구조**라 피초대자 마찰이 원천 0 — 랜딩·온보딩 카피에 명시("부모님은 아무것도 설치하지 않으셔도 됩니다"). 피보호자 등록 시 **"부모님께 보낼 안내 문자" 프리필** 제공(첫 통화 전 "딸/아들이 신청한 건강 확인 전화가 갈 거예요" 원터치 전송) → 첫 콜 응답률과 동의율 동시 상승.
- 출처: https://support.life360.com/hc/en-us/articles/23053409850647 · https://pageflows.com/post/ios/onboarding/life360/

### 1-2. 무료→유료 전환: "쓰다 보면 자연히 부딪히는 결핍"
- **패턴**: 무료 = Place 2곳·히스토리 2일·SOS, 영구 무료 포지셔닝. 유료 Silver $7.99 / Gold $14.99 / Platinum $24.99 — **가격은 서클(가족) 전체 커버**. 페이월은 팝업이 아닌 **상설 Membership 탭**. `Try 7 Days Free` → 첫 3개월 50% → 정가. 실적: MAU 9,580만, 유료 서클 280만, ARPPC $137.63.
- **심리**: 핵심 안심 가치는 무료로 풀어 습관·네트워크 형성, 제한 항목은 **사용할수록 자연히 부딪히는 벽**(집·직장 2곳 쓰면 3번째=부모님 댁이 필요해짐). 쌓인 히스토리를 못 보게 되는 손실 회피. "가족 전체 1가격"은 1인당 환산가를 싸게 인식시킴.
- **적용안**: 무료 = 주 N콜 + 요약 리포트 + 히스토리 7일 / 유료 = 매일 콜 + 상세 전사·추이 + 무제한 히스토리. 설정 옆 **상설 '이용권' 탭**. 가격 단위는 "피보호자 1명당"이 아니라 "우리 가족 안심 요금 1개".
- 출처: https://www.life360.com/plans-pricing · https://www.globenewswire.com/news-release/2026/03/02/3247854/0/en/life360-reports-record-q4-2025-results.html

### 1-3. 알림 설계: No-Show Alerts — "침묵이 기본, 예외만 알림"
- **패턴**: "○○가 △△시까지 도착하지 않으면 알려줘" 설정 → **정상 도착 시엔 아무 알림도 안 옴**, 미도착 시에만 수 분 유예 후 통지 ("a smart, silent safety net"). 일상 데이터는 주간 요약으로 다이제스트화.
- **심리**: 알림 피로의 해법을 "알림 줄이기"가 아닌 **예외 기반(exception-based) 모니터링**으로 재정의. "무소식이 희소식" 멘탈 모델과 일치. 실시간 채널에 예외만 남기면 채널 신뢰도가 보존됨.
- **적용안**: **DONE은 조용히 대시보드에만 기록, NOT_DONE/MISSED/UNCERTAIN만 즉시 알림.** 설정에 "모든 결과 / 이상 신호만(권장) / 주간 요약만" 3단 알림 레벨.
- 출처: https://techcrunch.com/2025/08/20/life360-adds-a-new-no-show-notification-to-its-app

### 1-4. "안심"의 패키징: 주간 리포트 카드 + 이중 수혜 카피
- **패턴**: 감시가 아닌 안심(peace of mind)·자유(freedom) 프레임. 고령 부모용 카피: "부모님이 원하는 자유를 드리면서, 당신이 필요한 안심을 얻으세요" — **부모의 자유 + 자녀의 안심을 한 문장에**. 주간 Family Driving Summary를 "report card"로 브랜딩, 유료 기능으로 묶음.
- **심리**: 감시 도구의 죄책감을 "부모의 독립을 지켜주는 도구"로 리프레이밍해 결제자의 자기 정당화 제공. 주간 리포트는 구독 가치를 **매주 눈에 보이는 산출물로 물화** — "내가 뭘 위해 돈 내지?" 해지 질문 선제 차단.
- **적용안**: 주간 이메일을 "이번 주 부모님 리포트 카드"로 브랜딩(이행률+플래그 추이+전주 대비). 카피를 "부모님의 일상은 그대로, 확인은 저희가" 식 이중 수혜 구문으로 통일.
- 출처: https://www.life360.com/aging-parents

## 2. 국내 케어 플랫폼 — 케어닥·케어네이션·똑닥

### 2-1. 케어닥: 신뢰 스택 + 가격 확정
- **패턴**: 간병인 프로필에 사진→경력→자격증→이력→후기→등급 배지를 층층이. 업계 최초 **간병비 정찰제** + 배상책임보험 **자동 가입** + 돌봄 시작/종료 시각 실시간 표시.
- **심리**: "모르는 사람에게 부모를 맡긴다"는 불안을 사회적 증거+권위+구체 이력으로 해소. 가격 확정 = 불확실성 회피("얼마 나올지 모른다"가 최대 장벽). 실시간 진행 표시 = 원격 통제감.
- **적용안**: ① 크레딧 차감을 "통화 1회 = N크레딧 확정" 사전 고지 + "이번 달 예상 사용량" 미리보기. ② **통화 진행 상태(발신 중→통화 중→분석 중→리포트 완료) 실시간 표시**. ③ 랜딩에 AI 통화 샘플 음성 + 실사용 후기 신뢰 스택.
- 출처: https://platum.kr/archives/141660 · https://caredoc.kr/

### 2-2. 케어네이션: 기록의 자산화 (간병일지 → PDF 활동확인서)
- **패턴**: 간병일지 → 보호자 열람 → **PDF '활동확인서' 자동 변환 → 보험사 간병비 청구에 실사용**. 역경매 매칭(보호자가 직접 선택), 무료 간병비 계산기. 2024년 매칭 거래액 540억, 회원 55만+.
- **심리**: 케어 기록이 **금전 가치가 있는 공식 문서**가 되는 순간 기록·열람 동기 급상승("리포트 = 증빙"). "내가 골랐다" 통제감. 반면교사: 간병인 노쇼가 최다 불만 — 약속 불이행 대응 부재가 신뢰를 깎는 1순위.
- **적용안**: ① 리포트를 누적 "복약 이행 기록" **PDF 내보내기**(월별 이행률+요약) — "진료 시 의사에게 보여주세요" 프레이밍으로 리포트를 자산화(이탈 방지 장치). ② MISSED(우리의 '노쇼') 방치 금지 — 재시도 결과와 다음 조치를 리포트에 반드시 명시.
- 출처: https://www.carenation.kr/

### 2-3. 똑닥: 가족 대리 접수 + 실시간 순번 + 저가 구독
- **패턴**: ① 가족 정보를 내 계정에 등록 → 본인 인증 없이 대리 예약·접수(접수 주체와 진료 대상 분리 — 우리와 동형). ② 접수 즉시 순번·대기·예상 시간 + 임박 푸시. ③ 2023-09 무료→**월 1,000원/연 10,000원** 유료화 — 결제 동인은 기능이 아니라 "소아과 오픈런 불가능"이라는 시간 손실 회피 + 대체 불가능성.
- **심리**: 등록 가족이 늘수록 전환 비용 증가(락인) + "가족을 내가 챙긴다"는 역할 수행감. 불확실한 대기→예측 가능한 대기. '껌값' 가격으로 지불 정당화 문턱 최소화.
- **적용안**: ① **"부모님 프로필 완성도" 게이지**로 추가 입력 유도(정보가 쌓일수록 락인). ② 가격 앵커: 국내 보호자 지불의사 하한 = 똑닥 1,000원, 상단 근처 = 위식스/SKT 4,950원. ③ 결제 소구는 기능 나열이 아니라 "매일 전화 걸 시간을 대신함"(시간 손실 회피).
- 출처: https://www.bizhankook.com/bk/article/26076

### 2-4. 직접 유사: 클로바 케어콜 콘솔 · SKT AI가족안부전화
- **패턴**: 클로바 관리자 콘솔 = "통화 내용을 일일이 확인하지 않아도 **이상 징후 대상자를 한눈에**" + **최근 4회 통화 추이** + 미수신자 휴먼 백업. SKT AI가족안부전화(월 4,950원): 요일·시간 설정 → 부모 앱 불필요 → 보호자 앱에서 수신 여부·요약·리포트, **가족 최대 10명 공동 열람**.
- **심리**: 보호자는 전체 로그가 아니라 "문제 있는 것만" 보고 싶어 함(예외 관리). 추이 뷰는 "상태가 나빠지고 있는가"라는 진짜 질문에 답함. 가족 공동 열람 = 형제자매 간 **분산된 죄책감** 활용 — 지불자 외 가족도 서비스에 묶임.
- **적용안**: ① 대시보드 최상단 "오늘의 이상 신호 0건 ✓" + 최근 5회 추이 스파크라인(전체 기록은 하위로). ② **가족 초대(읽기 전용 공동 열람)** 백로그 등재.

## 3. 복약/건강 앱의 리텐션 패턴

### 3-1. Medisafe Medfriend: 보호자 연결 = 최강 리텐션 (90일 잔존 +59%)
- 본인이 리마인더를 **모두 무시한 뒤에야** 보호자에게 푸시, 문구는 "약 챙기시라고 한마디 해주세요" **행동 제안형**.
- **심리**: 사회적 책무성. 1차 책임은 본인, 보호자는 최후 안전망이라는 **단계화**(즉시 고자질하면 자존감 훼손 + 알림 피로).
- **적용안**: MISSED 즉시 경보 금지, 재시도 소진 후에만. 알림에 **"지금 직접 전화해보시겠어요?" tel: 원버튼**으로 보고→걱정→연락의 마찰 0.

### 3-2. 스트릭: 케어 맥락에선 "리셋 없는 누적형 + 내장 용서"로 변형
- Duolingo 스트릭의 핵심은 용서 메커니즘(Streak Freeze). 그러나 정서 민감 카테고리에서 복구 불가 스트릭은 "결함의 증거"처럼 느껴져 **회피·이탈** 유발 (연구 다수).
- **부모의 복약 스트릭이 끊겼다는 표시는 자녀에게 죄책감을 전가**하고, 죄책감은 "앱 안 열기"를 낳음.
- **적용안**: 스트릭 금지. ① **리셋 없는 누적형**("이번 달 잘 챙긴 날 24일") ② POSTPONED/UNCERTAIN은 기록을 깨지 않음(빌트인 용서 — "억지 판정 금지" 원칙과 일치) ③ "끊김" 표현 금지, "다시 시작" 프레임만. **월간 캘린더 히트맵**(채워지는 캘린더) 권장.

### 3-3. 주간 리포트: 화요일 발송 + 개인화 제목 + 긍정 프레이밍
- 벤치마크: 개인화 푸시 오픈율 14.4% vs 일반 4.19%(3배), 이메일 **화요일 오픈율 최고(31.27%)**, 저녁 20시대 피크. 약 16,000명 글로벌 연구: 손실 프레임은 행동 변화 없이 **불안만 증가** — 고령·가족 맥락은 이득 프레임이 효과적.
- **적용안**: 주간 이메일 **화요일 오전 발송**, 제목 개인화 안도 프레임("어머니, 이번 주 잘 지내셨어요 — 복약 6/7"). 본문: 축하 헤드라인 → 이행률 카드 → 플래그 추이 → "확인 필요" 항목은 경보가 아닌 다음 행동 제안. UNCERTAIN은 "실패"가 아니라 "확인 필요"로 표기. "5/7 완료"(성취) ≻ "2회 놓침"(실패).

### 3-4. watcher 설계: Apple Health Sharing · Snug
- Apple: 데이터 주인이 공유 항목 선택(통제권 본인), watcher는 **하이라이트+장기 추세**만, **변화 감지 시에만** 알림, 이상 시 원버튼 연락. Snug: 정상 무음, 놓치면 가족 문자 → (유료) 관제 인력 선확인.
- **원칙**: "무소식이 희소식". 파는 것은 데이터가 아니라 **"안 봐도 되는 안심"**.
- **적용안**: 대시보드 = 추세+하이라이트(정상은 차분한 초록), 알림 = 예외만 단계 에스컬레이션. mood_flag/health_flag는 매회 나열하지 말고 **변화 감지 시에만** 표면화("지난 2주 대비 기분 언급이 달라졌어요").

### 3-5. 필리(Pilly): 카톡 알림 + 가변 보상 + "해지 대신 연기"
- 앱이 아닌 **카카오톡으로 매일 체크 알림+링크**(설치 장벽 0). 체크 시 랜덤 포인트(가변 보상). 해지 흐름에서 **연기·일시정지를 챗봇으로 먼저 제시** → 해지 빈도 감소 확인. 신규의 월 25%가 추천 유입.
- **적용안**: ① 해지 흐름에 **"발신 일시정지"(여행·입원 시 1주/1개월)**를 해지보다 먼저·크게. ② 보호자 접점 채널로 카카오(알림톡)가 이메일보다 국내 검증됨(§4). ③ 월간 캘린더 히트맵.
- 출처: https://www.mobiinside.co.kr/2019/12/19/pilly/

## 4. 카카오 알림톡 — 도입 가치 판단: **강력 추천**

## 5. 페이월/무료체험 설계 (2024–2026 벤치마크)

- **freemium이 정합**: 하드 페이월 전환율은 5배지만, 가족·네트워크 제품은 무료 사용자가 곧 배포 채널(Life360 사례). 1년 유지율은 동일(27~28%).
- **트라이얼**: 17~32일 전환율 42.5~45.7%로 최고(4일 미만 25.5%) — 주간 리포트를 2회는 받아봐야 가치를 아는 제품엔 14~30일. 트라이얼 시작의 82~90%가 Day 0 발생 → 온보딩 안 오퍼 배치가 결정적. **리버스 트라이얼**(카드 없이 프리미엄으로 시작 → 종료 시 무료 티어로 다운그레이드): free→paid 전환 10~40% 개선.
- **심리**: 보유 효과 + 손실 회피 — "업그레이드하면 얻는 것"이 아니라 "다운그레이드하면 잃는 것"(쌓인 상세 리포트·히스토리)으로 프레임 반전.

## UX 백로그 10 — 임팩트 순 (난이도 상/중/하)

1. **[중] 알림톡 예외 기반 알림**: NOT_DONE/MISSED/UNCERTAIN 발생 시에만 통화 직후 알림톡(리포트 딥링크 + "부모님께 전화하기" 버튼), DONE은 무음. 템플릿 심사 7~10일 선행 리드타임. ⚠️ 현재 베타 스코프 OUT(알림톡) — 재검토 필요.
2. **[하] 대시보드 "오늘의 안심 요약"**: 최상단 "이상 신호 0건 ✓" 배지 + 최근 5회 추이 스파크라인, 전체 통화기록은 하위로.
3. **[하] 주간 이메일 리포트 카드화**: 화요일 오전 + 개인화 안도 프레임 제목 + 성취 프레이밍.
4. **[중] MISSED 단계형 에스컬레이션**: 재시도 소진 후에만 알림, "지금 직접 전화해보시겠어요?" tel: 원버튼.
5. **[중] 리셋 없는 누적 지표 + 월간 캘린더 히트맵**: 스트릭 금지, POSTPONED/UNCERTAIN은 기록을 깨지 않음.
6. **[중] 통화 진행 상태 실시간 표시**: 발신 중→통화 중→분석 중→리포트 완료 (TelephonyAdapter 상태 콜백에 이미 부합).
7. **[상] 리버스 트라이얼 유료화**: 첫 달 프리미엄 무료(카드 없음)→무료 티어 다운그레이드, Day 27~28 월간 추이 리포트 직후 전환 오퍼. 상설 '이용권' 탭 + 비교 표.
8. **[중] 리포트 PDF 내보내기**: 월별 복약 이행 기록 — "진료 시 의사에게 보여주세요" 프레이밍.
9. **[상] 가족 공동 열람(읽기 전용 초대)**: 초대 코드 + 프리필 문구 방식.
10. **[하] 온보딩·해지 마찰 설계**: ① 등록 시 "부모님께 보낼 안내 문자" 프리필 + "부모님은 설치할 것이 없어요" 카피 ② 해지 흐름에 "발신 일시정지" 선제시.

### 종합 한 줄
검증된 공식은 **"정상은 침묵, 예외만 즉시(알림톡), 안도는 매주 정기 배달(화요일 리포트 카드), 기록은 자산화(PDF), 전환은 자연 결핍+리버스 트라이얼"** — 그리고 "보호자가 등록한 구체적 일정의 이행 확인 리포트" 포지션은 국내에 뚜렷한 선점자가 없다.
