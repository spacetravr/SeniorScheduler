## 1. iamfine (미국) — 자동 전화 체크인의 원조, 15년차 생존자

**상태**: 2026년 현재 정상 영업 중. 2011~2012년 두 형제가 어머니를 돌보기 위해 창업, 누적 400만+ 콜. 이 카테고리 최장수 서비스. 미국·캐나다·영국, 앱 없음(전화 100%).

- **(a) 가격**: **$14.99/월 또는 $120/년**(연납 시 약 $10/월). 14일 무료 체험(카드 등록 불필요), 무약정, 기기·설치비 0원. "체험자 8/10이 유료 전환" 주장.
- **(b) 콜 UX**: 시니어가 고른 시각에 자동 발신 → **전화 받고 "1번" 누르면 체크인 완료**(수 초). 유선·폴더폰 동작. **무응답 시 이후 1시간 동안 5회 추가 발신(총 6회)** — "재시도가 넉넉해서 한 번 못 받아도 가족이 시달리지 않는다"를 설계 철학으로 홍보. 시니어가 먼저 걸어 체크인도 가능. 휴가 모드(입원·여행 시 일시정지) 제공.
- **(c) 에스컬레이션·대시보드**: 1시간 재시도 전부 실패 시 **"Care Circle"(최대 8명)에 알림 — 이메일은 항상, SMS·자동 전화는 설정 시**. **알림 순서 커스터마이즈 지원**(예: 옆집 이웃 → 근거리 친척 → 원거리 자녀 순차). 본인 또는 Care Circle 누군가가 "OK" 처리하면 해소. 반면 성공 로그·리포트 대시보드는 빈약 — 리뷰들의 공통 지적이자 약점.
- **(d) 성공/실패 요인**: 성공 — PSTN-only로 기기·앱 장벽 제로, 15년 단일 기능 집중, "가족이 결제·설정, 부모는 1번만 누름"의 역할 분리, 넉넉한 재시도로 오경보 최소화. 비판 — 낡은 UX, 키패드 응답의 비인격성, 개인화 없음, 긴급출동(911) 없음.
- **(e) 베낄 것**: ① **"1시간 6회 재시도 후 에스컬레이션" 버퍼** — 오경보 억제가 리텐션의 핵심임을 15년으로 증명 (우리 1분/10분 재시도보다 완만한 커브 검토 가치). ② **Care Circle 순차 알림 편집기** + 휴가 모드 네이밍.
- 출처: https://dailycall.iamfine.com/ · https://dailycall.iamfine.com/pricing/ · https://help.iamfine.com/article/8-what-happens-if-i-as-the-loved-one-dont-check-in · https://www.checkrise.co/blog/iamfine-review/

## 2. 데일리 체크인 계열: Snug Safety · CareCheckers · Mon Ami · 관공서 무료 프로그램

### 2-1. Snug Safety (미국) — 앱 기반, 유일하게 '경찰 안부확인 출동 요청'까지
- **(a) 가격**: 무료 플랜(1일 1회 체크인+미체크인 시 비상연락처 SMS) / 멀티 체크인 애드온 $17.99/년 / **Dispatch 플랜 $19.99/월 또는 $199.99/년**(사람 디스패처 개입).
- **(b) 체크인 UX**: 마감시각까지 앱의 초록 버튼 탭. 리마인더 캐스케이드: **마감 3시간 전(무음 푸시) → 1시간 전 → 10분 전 → 마감 시각(푸시+SMS) → 마감 2분 후(푸시+SMS)**.
- **(c) 에스컬레이션**: 무료 — 마감 10분 경과 시 비상연락처 전원에 **마지막 GPS 위치 포함 SMS**. Dispatch — 10분 후 **디스패처가 본인에게 직접 전화(오경보 필터)** → 무응답 시 비상연락처 순차 전화 → 전원 실패 시 **관할 911에 웰니스 체크 요청**. 해소는 앱 또는 지정 번호 전화 → 가족에게 "OK" 자동 전파.
- **(d)**: 2016년 창업, 누적 2,000만+ 체크인, App Store 4.8+. 수년째 제품 업데이트 정체. 구조적 약점 — **스마트폰 앱 의존**: 푸시 놓침, 오경보로 한밤 EMS 출동 사례, 폴더폰 시니어 원천 배제. 우리 PSTN 접근이 정확히 이 약점을 침.
- **(e) 베낄 것**: ① **가족 알림 전 "본인에게 한 번 더 확인" 버퍼 단계**(오경보 필터). ② **해소(resolve) UX** — 상황 종료 시 가족에게 자동 "OK" 통지로 불안 루프를 닫음.
- 출처: https://www.snugsafe.com/ · https://snug.helpscoutdocs.com/article/29-what-to-expect-if-you-miss-a-check-in

### 2-2. CareCheckers (미국) — 실제 사람이 거는 라이브 콜, 고가
- 1콜/일 주5일 $29.95 ~ 3콜/일 주7일 **$129.95/월**. 사람이 1~5분 스몰토크, **가능하면 매번 같은 상담원 배정**(관계 형성). 무응답 시 1시간 내 3회 재시도 → 음성 메시지 → 비상연락처 통보.
- "기계는 다정한 목소리를 대체 못 한다" 포지셔닝의 대가가 월 $50~130 — 자동화 대비 3~9배로, AI 콜의 원가 우위 논거. **베낄 것: "같은 목소리" 정책** — 부모별 고정 TTS 보이스·호칭·인사말 유지.
- 출처: https://carecheckers.com/

### 2-3. Mon Ami (미국) — B2C 컴패니언십 → 정부(AAA) SaaS로 완전 피벗
- 2018년 대학생-시니어 말벗 매칭 마켓플레이스 → 2020년 팬데믹으로 대면 방문 소멸 → 자원봉사자 매칭 소프트웨어 → 현재 **노인·장애인 서비스 기관(AAA·주정부) 전용 케이스 매니지먼트 시스템**(8개 주 통째 도입). 전화 안부는 "남의 프로그램을 관리해주는 모듈"로만 잔존 — 번호 마스킹, 통화 시간 자동 기록.
- 구조적 배경: B2C 컴패니언십 마켓플레이스는 CAC 높고 마진 얇고 안전사고 리스크가 큼.
- **(e) 베낄 것**: **B2G 피벗 경로를 아키텍처 단계에서 열어두기** — 한국의 지자체 안부전화·노인맞춤돌봄이 미국 AAA에 해당. 멀티테넌시·기관용 리포트를 염두.
- 출처: https://www.monami.io/about-us/ · https://www.monami.io/case-studies/case-study-telephone-reassurance

### 2-4. 무료 경쟁: 관공서 전화 안부 (R.U.O.K. / Maryland Senior Call Check)
- 1990년대부터 미국 수백 개 카운티 보안관서가 **무료 자동 안부전화**(R.U.O.K.) 운영: 매일 자동 발신 → **전화를 받으면 그것으로 체크인 완료** → 무응답 시 키홀더(집 열쇠 보유자 2명+ 등록 필수) 접촉 → 실패 시 경찰 출동.
- **Maryland Senior Call Check**: 미국 최초 주 단위 무료(60세+). 1시간 블록 자동 전화 → 무응답 2회 재시도 → 대체 연락처 → 웰페어 체크. **가입은 반드시 본인이**(대리 가입 불가 — 동의 이슈의 미국식 해법).
- 무료의 한계 = 유료의 존재 이유: 시간대 블록 단위, 가족 대시보드 없음, 맞춤 내용 없음. 유료는 이 틈(맞춤 시각·가족 리포트·즉시 가입)으로 공존.
- **베낄 것**: ① **"받기만 해도 체크인" 최소 UX** — 인지력 낮은 어르신용 폴백 모드. ② **키홀더 플래그** — 에스컬레이션 연락처에 "집에 들어갈 수 있는 사람" 표시. ③ 본인 가입 원칙은 우리 동의 콜(CONSENT) 설계의 준거.
- 출처: https://www.brunswicksheriff.com/community-programs/ruok · https://aging.maryland.gov/Pages/senior-call-check.aspx

## 3. ElliQ (Intuition Robotics) — AI 컴패니언 로봇, B2G로 생존

- **(a)**: 등록비 $249.99 + **월 $59.99(월납)/$49.99(약정)**. 기기는 **리스**(구독 일체형). 2022년 대비 4년 만에 약 2배 인상 — B2C 판매가 주 수익원이 아니게 됐다는 신호.
- **(b)**: 뉴욕주 노인청(NYSOFA) 참가자 800명+ — 하루 평균 30회+ 상호작용, "외로움 95% 감소"(자기보고) 공동 발표.
- **(c)**: 사용자 대다수가 주정부·AAA·헬스플랜 경유 **무상 보급**(6개 주). 2026년 3월 **워싱턴주 Medicaid "Smart Care Device" 인정**. 2026년 일본 진출 예정.
- **보호자 앱**: 복약·수분 리마인더 원격 설정, 통증·기분 변화 보고 시 보호자 알림, **AI가 건강·행동의 유의미한 변화를 요약해 보호자에게 업데이트**.
- **(e) 베낄 것**: ① **"보호자가 목표 설정 → AI가 어르신에게 권유 → AI가 변화 요약을 보호자에게 리포트" 3각 루프**. ② **정부 파트너와 공동 발표하는 성과 지표**("외로움 95% 감소")가 최고의 마케팅 자산 — 한국이면 지자체·치매안심센터 시범사업 공동 성과 발표.
- 출처: https://elliq.com/products/monthly-subscription · https://aging.ny.gov/news/nysofas-rollout-ai-companion-robot-elliq-shows-95-reduction-loneliness

## 4. 복약 관리 계열: Medisafe · Hero Health · Pillo/Pria · MedMinder · PillPack

### 4-1. Medisafe — 복약앱 1,100만 사용자, Medfriend가 핵심 참고점
- 역사적으로 무료 + Premium $4.99/월. **2026년 1월 대규모 유료화**(무료 티어 약 2개 약물 제한) → 보호자들 반발, "부모는 앱을 안 쓰거나 지워버린다"는 구조적 문제 노출.
- **Medfriend 설계 (가장 직접적 참고)**: 가족을 Medfriend로 연결 → 본인 수차례 리마인드 후에도 미복용이면 **미복용 30분 후 Medfriend에게 푸시**. **알림에 약 이름 미포함 — "놓쳤다"는 사실만 전달**(프라이버시 계층). **효과: Medfriend 보유 사용자는 90일 지속률 +59%.**
- 파마 B2B로 피벗 — 추정 매출 약 70%가 제약사 환자지원프로그램.
- **(e) 베낄 것**: ① **"확정 실패 30분 후 보호자 알림 + 상세정보 최소화"** — MISSED 확정 시 즉시 통지, 상세는 리포트에서. ② **"보호자 연결 = 리텐션 +59%"** 정량 근거 — 보호자가 등록 주체인 우리 구조의 세일즈 포인트. ③ 반면교사: 부모가 앱을 직접 써야 하는 모델의 한계 = 우리 PSTN 방식의 정당성.
- 출처: https://medisafeapp.com/pro-tip-add-a-medfriend/ · https://medisafe.com/education-resources/the-impact-of-medisafes-medfriend-caregiver-feature-on-adherence

### 4-2. Hero Health — 스마트 디스펜서, 공격적 락인의 반면교사
- 구독 전용 — 12개월 선납 $29.99/월 ~ 무약정 $59.99/월 + 초기비 $99.99. **첫 1년 해지 위약금 $399, 기기 미반납 시 $1,500.**
- 에스컬레이션: **도즈 30분 전 예고 → 정시 비프+라이트 → 지각/미복용/재고부족 시 보호자 알림**(푸시/SMS/자동 전화 선택형).
- BBB·Trustpilot 불만 다수 — **위약금·미반납 청구가 최대 원천**. 직접 구독은 Medicare 비급여, **RTM(원격치료모니터링) 수가 코드 경유**로 의료기관 채널 개척.
- **(e) 베낄 것**: ① 단계 구분 + 보호자 알림 채널 선택형. ② 반면교사: 하드웨어 없는 우리는 "언제든 해지"를 차별점으로 명시. ③ 장기적으로 의료수가/공적 재원(일차의료 만성질환관리·장기요양 재가급여)에 태우는 경로가 정석.
- 출처: https://herohealth.com/pricing/ · https://herohealth.com/caregivers/

### 4-3. Pillo / Pria (BLACK+DECKER) — 사망 사례
- 음성 AI+얼굴인식 알약 디스펜서 로봇. $11M Series A → "Pria" **$749.99 선불** 출시 → 2020년 Stanley Black & Decker 인수 → 모회사 공구 집중 전략으로 **조용히 폐기**.
- **사인 3가지**: ① 대기업 CVC 의존 + 인수 후 모회사 전략 변경. ② $749 하드웨어 선불은 이 시장에서 안 팔림(생존자는 전부 구독 리스). ③ 다기능 통합은 각 기능이 어중간 — **"전화 한 통" 단일 인터페이스 집중의 반대 극단 실패 사례**.

### 4-4. MedMinder — 업계에서 가장 명확한 에스컬레이션 체인
- 셀룰러 내장 잠금식 디스펜서, 월 $125. **에스컬레이션: 도즈 시각 칸 점멸(7:30) → 30분 후 비프(8:00) → 30분 후 본인에게 전화(8:30) → 그래도 미복용 시 모든 보호자에게 전화/이메일/문자.** 비프음 대신 **가족 목소리 녹음 리마인드** 가능.
- **베낄 것**: **"30분 간격 4단계(기기→기기→본인 전화→보호자)" 체인**과 **가족 목소리 리마인더** — ARS+ 설계 이식 최우선 후보.
- 출처: https://medminder.com/

### 4-5. PillPack (Amazon Pharmacy)
- 날짜·시각 인쇄된 1회분 파우치 월 배송 — **포장 자체가 리마인더이자 복약 기록**. 2018년 Amazon $753M 인수.

## 5. 케어 코디네이션 계열: Papa · DUOS · ianacare

### 5-1. Papa — 안전 스캔들 1건으로 고객 1/3 상실
- 2017년 "grandkids on demand" B2C → 2020년부터 Medicare Advantage 보험사 PMPM B2B2C 전환, 2024년 약 100개 플랜.
- **2023 스캔들**: Bloomberg가 4년간 **1,200건+ 내부 민원(성폭력·절도 등)** 폭로 → **약 36개 플랜/고용주 이탈**. 이후 "의료비 9% 절감, 입원 18% 감소" 정량 아웃컴으로 재무장해 생존.
- **(e) 교훈**: ① 취약계층 서비스는 **안전사고의 언론화 1건이 B2B 계약 전체를 무너뜨림** — 사고 건수보다 "대응 체계 부재"가 치명타. ② 감성 가치만으로는 계약 방어 불가 — **정량 지표 증명**이 생존 조건.
- 출처: https://www.bloomberg.com/news/features/2023-05-30/papa-eldercare-startup-faces-abuse-claims-by-seniors-caregivers

### 5-2. DUOS — B2C 포기, 보험사 KPI 정렬로 $130M
- 초기 인간 비서 배치 모델 → 보험사용 "performance infrastructure"로 완전 피벗(검진 완료·지원 프로그램 등록·처방 갭 탐지). **2025년 10월 $130M 성장자본**.
- 교훈: 시니어 순수 B2C는 지불의사 한계 → **지불자(보험사)의 재무 KPI에 AI를 정렬**시킨 쪽이 대형 조달에 성공.

### 5-3. ianacare — 무료 앱은 획득 채널, 수익은 고용주·정부
- 가족·지인 돌봄 팀 배분 **무료 앱** + 고용주·보험이 구매하는 B2B2C. CMS GUIDE(치매 돌봄) 모델 파트너십.

## 6. 2024~2026 신규 AI 보이스 체크인 콜 스타트업 (가장 직접 경쟁/참고)

2024~2026년에 "앱 없음·기기 없음·일반 전화" AI 안부콜이 하나의 카테고리로 성립. 최소 8개 신생, 가격 $15~49/월 수렴.

### 6-1. inTouch (intouch.family, 2024) — 가장 직접적 벤치마크
- 유럽 €29.90/월, 미국 $29/월 무제한. AI 음성 "Mary"가 매일 유선·피처폰 발신, 10~15분 대화. 1,400개+ 질문 라이브러리로 점진 학습. **시니어 처리 속도 고려해 응답에 의도적 3초 지연.**
- 자녀 앱에 통화별 요약 + **무드 지표** + 주제 인사이트. **부재중 1회는 알림 없이 리포트에만 기록, 반복 부재 "패턴"만 경보** — 과잉 알림 억제 설계.
- 404 Media "자녀가 귀찮아서 AI를 시키는 디스토피아" 비판 — "자녀 대체" 포지셔닝의 역풍 사례.
- **(e) 베낄 것**: ① **패턴 기반 에스컬레이션**(단발 MISSED는 조용히, 연속 2~3회부터 보호자 푸시 — 설정 옵션으로). ② 무드 지표+주제 요약의 초간단 리포트 포맷.
- 출처: https://intouch.family/en · https://www.404media.co/i-tested-the-ai-that-calls-your-elderly-parents-if-you-cant-bothered/

### 6-2. Meela (meela.ai, 2024)
- $3.5M 시드, B2C 약 $40/월 + 시니어리빙 B2B. 90일 리텐션 50%+, 평균 통화 10분+. **매 통화 시작 시 AI임을 자기고지.** 약점: **통화 종료 처리 미숙**(끊으려는 사용자에게 반복 질문).
- **베낄 것**: ① 도입부 AI 자기고지(우리 동의 콜·전기통신사업법 대응과 일치, 신뢰 마케팅 요소). ② **"통화 종료 UX"를 명시적 설계 항목으로**(작별 인사 후 재질문 금지 룰).

### 6-3. ElderVoice — 에스컬레이션 룰이 가장 명확
- 가족이 웹에서 계정 생성 → 부모 전화번호·**복약 스케줄**·관심사 입력 → 지정 시각 발신(우리와 온보딩 구조 가장 유사). **무응답 시 1시간 내 3회 재시도 → 1차 가족 연락처 알림.** 응급 키워드 감지 시 즉시 SMS + **"911 대체 아님" 명시**. 통화 직후 SMS/이메일 일일 요약.

### 6-4. JoyCalls (2025-09 출시) — 분량제 과금

### 6-5. 기타 신생
- **Callie Care** ($15/월 무제한, 2026-07 $500K 프리시드): 양방향 + **통화 중 실행형 태스크**(교통 예약·장보기) 로드맵. MVP 8개월 만에 8,000+ 사용자.

### 6-6. 일본우편 「みまもりでんわ」 — 국가 스케일로 검증된 PSTN 안부콜

## 7. 종합

### 7-1. 반복 검증된 성공 패턴
1. **PSTN·무기기·무앱이 이긴다.** iamfine(15년), 일본우편, 신생 8개사 전부 "일반 전화 한 통"으로 수렴. 앱 기반(Snug)은 구조적 약점, 하드웨어($749 Pria)는 사망.
2. **DTMF 버튼 응답이 최종 폴백.** iamfine "1번", 일본우편 "1/2/3", CareCalls "아무 버튼" — 음성 인식이 좋아져도 버튼이 확실. 우리 "DTMF 우선 → 키워드 룰" 순서가 정답.
3. **오경보 관리가 곧 제품.** 생존 서비스 전부가 "가족 알림 전 버퍼"에 설계력 집중 — iamfine 1시간 6회, Snug 디스패처 확인콜, 일본우편 2연속 룰, inTouch 패턴 경보. 불필요한 가족 알림이 해지 사유 1위 요인.
4. **"보호자가 결제·설정, 부모는 받기만" 역할 분리 + 보호자 연결 = 리텐션** (Medisafe Medfriend +59%).
5. **에스컬레이션 표준형**: 본인 다단계 리마인드(수분~30분 간격 3~6회) → 확정 실패 후 30~60분 내 보호자 통지(채널 선택형, 상세 최소화) → 순차 연락망 → (별도 유료 티어) 출동. **해소 시 가족에게 자동 "OK" 전파**로 루프를 닫는다.
6. **리포트 포맷 수렴**: 통화 완료 여부 + 구조화 체크 + 무드 지표 + 특이 발언 요약의 4요소 — 우리 call_reports 스키마와 일치(검증된 포맷이라는 방증).
7. **가격 앵커**: 자동화 콜 $15~29/월(₩2만~4만), 일본우편식 초저가 ¥1,070, 인간 콜 $50~130. AI 대화형은 $19~29.
8. **장기 생존 공식은 B2B2C/B2G 병행.** 순수 B2C만으로 크게 된 곳 없음 — ElliQ(주정부·Medicaid), Medisafe(제약), Hero(RTM 수가), DUOS·Papa(보험사), Mon Ami·ianacare(정부·고용주). 한국 대응: 지자체 노인맞춤돌봄·치매안심센터·건보 시범사업·기업복지·상조/보험 제휴.

### 7-2. 반복된 실패 함정
1. **부모가 앱/기기를 직접 다뤄야 하는 모델** (Medisafe 유료화 반발, Snug, Pria).
2. **하드웨어 선불 + 다기능 통합** (Pillo/Pria). 생존자는 전부 구독형 + 단일 인터페이스.
3. **안전·신뢰 사고의 언론화** (Papa: 기사 1건에 고객 1/3 이탈). AI 콜에서는 "위험 신호 미탐지"가 같은 유형의 존폐 리스크. **"불확실하면 UNCERTAIN" 원칙이 곧 안전 정책이다.**
4. **공격적 락인** (Hero 위약금 $399). "언제든 해지"가 이 시장의 신뢰 기본값.
5. **"자녀를 대체한다" 포지셔닝** (inTouch 역풍). "자녀가 못 챙기는 시간을 보완한다"로 포지셔닝해야 함.
6. **대기업 CVC·소수 대형 고객 의존** (Pillo, Papa).
7. **화려한 실패보다 조용한 정체** — 전형적 사인은 수년간 무업데이트(Snug, LifePod, CareAngel). 단일 기능에 머물면 정체한다.

### 7-3. 우리 로드맵 기능 우선순위 제안 5개
1. **[베타 필수] 부재중 패턴 기반 보호자 알림 설정** — 기본값: MISSED 1회는 리포트에만 조용히, 연속 2회부터 즉시 알림(채널 선택형). "즉시/패턴/조용히"를 스케줄별 설정. (inTouch + 일본우편 + Medisafe 30분 룰 종합. 알림 피로 = 해지 1위 요인 차단.)
2. **[베타 필수] 자녀 녹음 인트로 10초** — TTS 본문 앞에 자녀가 녹음한 인사("엄마, 나 OO야. 약 드실 시간이에요"). 응답률·수용성 직결, 보이스 클로닝 금지 원칙을 지키면서 정서 효과를 얻는 합법적 우회로. (CareCalls UK + MedMinder 검증.)
3. **[베타 필수] AI 자기고지 + "긴급구조 대체 아님" 고지 세트** — 도입부 AI·녹음 고지를 신뢰 마케팅 요소로 전면화, "119 대체 아님" 면책을 랜딩·리포트 하단 고정.
4. **[v1.x] Care Circle 순차 연락망 + 키홀더 플래그 + 해소 UX** — 연락처 3~8명, 순서·채널 편집. "집에 들어갈 수 있는 사람" 플래그. 해소 시 전원 자동 "OK" 전파. 경비업체 출동 옵션은 별도 유료 티어 소재.
5. **[확장] B2G 멀티테넌시 대비 + 원가 연동 요금제** — 기관 대시보드 SaaS 경로를 스키마 단계에서 열어두고, cost_krw 데이터로 JoyCalls식 분량제 티어 설계. 정부 파트너 공동 성과 발표를 마케팅에 포함.

**포지셔닝 결론**: 조사한 해외 서비스 전부가 "생존 확인" 또는 "말벗/외로움"이 1차 가치이고, **"자녀가 등록한 복약·병원 일정의 이행 확인 + 분류 리포트(DONE/NOT_DONE/POSTPONED/UNCERTAIN)"를 1차 가치로 내세운 곳은 글로벌하게도 없다**(ElderVoice가 복약 스케줄 입력을 받는 정도). 우리의 일정 이행 중심 설계는 유효한 차별화 포인트이며, 검증된 부품(DTMF 응답, 재시도 버퍼, 순차 알림, 4요소 리포트)을 조립하되 이 축을 놓치지 않는 것이 핵심.
