## 2. 첫 게시물 (카드뉴스 Set 01, 6장)

**캡션**:
```
"엄마, 오늘 약 드셨어요?" 매일 여쭤보고 싶은데, 현실은 자꾸 깜빡하게 되죠.

Senior Scheduler는 보호자가 등록한 복약·병원 일정에 맞춰
부모님의 일반 전화로 안부 전화를 걸고, 결과를 리포트로 알려드리는 서비스예요.

✅ 부모님 폰에 앱 설치 필요 없음
✅ 못 받으시면 자동 재시도
✅ 음성 녹음은 저장하지 않아요 (텍스트 요약만)
✅ 부모님 본인 동의 후에만 발신

지금 베타 사전등록하시면 출시 소식을 가장 먼저 보내드립니다. (무료, 결제 정보 없음)
🔗 프로필 링크에서 30초 만에 등록하세요.
```

