## 본문 캡션

```
전화가 끝나면, 보호자에게는 이런 리포트가 도착합니다.

별일 없던 날은 한 줄이면 충분합니다.
"오늘은 이상 신호가 없었어요."

문제는 애매한 날입니다.
"먹었나… 아까 먹은 것 같기도 하고."
이런 답을 억지로 '완료'로 만들면 리포트는 보기 좋아지지만,
믿을 수 없게 됩니다.

그래서 저희는 확실하지 않은 건 "확인 필요"라고 그대로 알려드립니다.
모르는 건 모른다고 말씀드리는 쪽이, 결국 더 쓸모 있으니까요.

알림도 같은 원칙입니다.
이상이 없으면 알림도 오지 않습니다.
확인이 필요한 일이 있을 때만 알려드리고,
알림 범위는 [모든 결과 / 이상 신호만 / 주간 요약만] 중에 고르실 수 있습니다.

* 카드의 리포트 화면은 이해를 돕기 위한 예시입니다.
* 시니어 스케줄러는 의료 조언을 제공하지 않으며, 긴급 구조를 대행하지 않습니다.

베타 사전등록을 받고 있습니다. 프로필 링크에서 등록해 주세요.
```

## 댓글 응대 가이드

- "확인 필요가 많으면 소용없는 거 아닌가요?" → "억지로 완료 처리하는 것보다 낫다고 봅니다. 확인 필요는 그 시간에 다시 여쭤볼 지점을 알려드리는 신호입니다."
- "실제 화면인가요?" → "예시 화면입니다. 실제 리포트도 같은 구조(한 줄 판정 → 일정별 결과 → 요약)로 나갑니다."
- 알림 문의 → "기본값은 '이상 신호만'입니다. 설정에서 언제든 바꾸실 수 있습니다."
- 응급 상황 관련 질문 → "응급 상황을 감지하거나 긴급 구조를 대행하지 않습니다. 위급하다고 판단되시면 119에 연락해 주세요."
